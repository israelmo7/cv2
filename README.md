# cv2 → Cat Bank

This repo started as an OpenCV template-matching experiment ([`temp.py`](temp.py)).

The active project is **[cat_bank](cat_bank/)**: a live webcam YOLO app that builds a named cat bank while streaming.

```bash
cd cat_bank
pip install -r requirements.txt
python main.py
```

See [cat_bank/README.md](cat_bank/README.md) for controls and setup.
